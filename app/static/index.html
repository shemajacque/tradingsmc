1. Host this app

  1. Deploy with Docker: docker compose up -d.
  2. Set SMC_ADMIN_PASSWORD to a long random value.
  3. Put it behind HTTPS (Caddy, nginx, Render, Railway, Fly.io).
  4. Keep SMC_DEMO_ONLY=1 until a setup is validated.

2. Create a token

  1. Open Bots & tokens, click New token.
  2. Choose the account login/server it is for.
  3. Copy the token immediately; it is stored hashed.

3. Load the EA in MT5

  1. Attach SMC_Link to a chart on the demo account.
  2. InpAppUrl = your app URL, e.g. https://bot.example.com.
  3. InpToken = the token from step 2.
  4. Enable Tools > Options > Expert Advisors > Allow WebRequest, add the exact app origin and press Ok.
  5. Use HTTPS on port 443. MT5 WebRequest ignores custom ports such as :8010.
  6. The bot card here turns online and shows the account snapshot.

4. Local live account

Run this app on the same Windows machine as MT5 to unlock the Live account tab. It reads balance, positions, orders and history directly from the terminal, with an equity curve, 30-day performance, exposure, SL risk / R:R, risk-based lot sizing, partial close, break-even and close-all actions. Real-account manual orders require SMC_ALLOW_LIVE_TRADING=1. On Docker/Linux, use the EA heartbeat instead.

5. Bot execution

The link EA validates the token, heartbeats and reports the account. Automated execution is enabled only after the strategy passes the research gate shown in the Research tab. This prevents activating a negative-expectancy setup.

6. AI agent

Open the AI Agent tab to run the SMC signal engine with an adaptive scoring brain, risk gates and MT5 execution. Start in Paper mode first: it logs signals without placing orders. Uncheck paper only when you want demo execution. Real accounts stay locked until the research gate passes and SMC_ALLOW_LIVE_TRADING=1.
